# Vulkan Tutorials

Questo repository contiene vari progetti e tutorial per imparare a utilizzare le API di Vulkan in C++. 

Ogni cartella all'interno di questa repository rappresenta un tutorial differente o uno step incrementale nello sviluppo:

- **[vulkan-game-engine](./vulkan-game-engine)**
- **[vulkan-lez01](./vulkan-lez01)**

Ogni progetto è indipendente e configurato tramite CMake, utilizzando `vcpkg` (in modalità manifest) per la gestione delle dipendenze come Vulkan, GLFW e GLM.
