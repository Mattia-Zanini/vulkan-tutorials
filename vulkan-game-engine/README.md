# Vulkan Game Engine Tutorial

Questo progetto segue il tutorial su Vulkan basato sulla seguente playlist di YouTube:
[Vulkan Game Engine Tutorial - Playlist YouTube](https://youtube.com/playlist?list=PL8327DO66nu9qYVKLDmdLW_84-yE4auCR&si=LFdAc6dxzHNQ4oXz)

Il codice sorgente originale e la repository di riferimento si trovano qui:
[GitHub - blurrypiano/littleVulkanEngine](https://github.com/blurrypiano/littleVulkanEngine)

Le librerie principali utilizzate nel progetto sono:
- **Vulkan**
- **GLFW** (al posto di SDL)
- **GLM**
- shaderc, spdlog, fmt

## Ambiente di Sviluppo
Il tutorial è stato seguito e testato sul seguente sistema:
- **OS**: macOS Sequoia
- **Architettura**: ARM64
- **Chip**: Apple Silicon M2
